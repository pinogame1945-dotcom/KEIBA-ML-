# L2 期待値AI1位軸・赤字→黒字化の全券種事前学習テスト（V1）

## 結論
2023年学習→2024年未知年評価、2023+2024年学習→2025年未知年評価という厳密な年別Walk-forwardを実行した。

**現行の「全レースに近い購入機会を維持する」固定点数方式では、検証した3つのチケット選択法のどれも2024・2025両年の黒字化に至らなかった。** 黒字だった245オッズ帯だけを抜き出す方式は採用せず、以前の赤字帯も含む全候補を対象とした。

- 2023: 3,456レースを学習する年（最適化結果の未知年成績は**出さない**）。
- 2024: 3,456レースのうち3,454レースで購入候補に価格があった。2023年のみで学習した状態で評価。
- 2025: 3,456レースのうち3,455レースで購入候補に価格があった。2023・2024年だけで学習した状態で評価。
- 2026: 未使用。
- 無料標準 GitHub Actions CPU、BACKFILL履歴はmanifest確認後、固定コミットを一度だけ取得。計算用の履歴データをGitHubに保存しない。

## 赤字券種が黒字に変わった例：ただし再現性なし

|---|---:|---:|---:|---:|---:|
| 三連単・順位差RANK・1レース1点 | 189.75101332% | 21.55716353% | **105.64191634%** | **+38,980円** | 6,909 |

同じ方式の全候補無選別ROIは **71.04069520%**。この意味では「赤字券種全体から、事後の2年合計では黒字となる買い目が作られた」例が1件存在する。

しかし**2024年+310,000円、2025年-271,020円**という偏りが強い。2024・2025の両年で黒字だった最適化パターンは **0件**。したがって「赤字ラインを安定して黒字化できた」とは判断しない。

ほかの券種の全候補無選別は馬連71.72861959%、ワイド74.56875446%、馬単71.30457897%、三連複67.88634908%、複勝83.05977710%、単勝85.94152555%。上限点数を削って改善した事例もあるが、今回の2年通算で各券種の赤字を黒字に変えた方式は上記三連単以外になかった。

## モデルと取り扱い

- 軸は**期待値AI1位の同じ馬のみ**。市場1位・AI1位への軸変更はない。
- 購入候補は単勝・複勝・馬連・ワイド・馬単・三連複・三連単の7券種。相手馬は市場人気順、市場補正AI順、純AI順それぞれの上位10頭の和集合。原研究の152買い方を包括する設計だが、**全出走馬とのすべての組み合わせを無制限に列挙したものではない**。
- オッズの事前黒字帯フィルタは使用しない。赤字帯を含む、取得できた全オッズ帯が候補。
- 1点100円、掛け金可変の方式だけスコアにより100〜300円。「可変掛け金」は検証用の固定段階倍率であって、精密なKelly最適化ではない。
- 的中・払戻は公式結果で精算。ソート・意思決定は同一年の的中結果を見ず、過去年の集計、当該馬券オッズ、事前の馬評価順位差だけを利用。
- **重大な実運用制約:** 検証時の馬券オッズは過去の**最終オッズ**で、締切前に入手・約定できる価格の検証ではない。そのため「未知年」と記していてもリアルタイム購入可能性の証明ではない。
- 結果を見てから「最高ROIの方式」を採用してしまうと後付けの選択バイアスが生じる。本レポートの各比較は診断用であり、現時点で本番採用できる勝利ルールは確定していない。

## 全数データ
- `all-policies-by-year.csv` — 2023の無選別母集団および2024・2025年度別の全結果。購入レース・点数・的中レース・的中点数・ROI・損益・最大ドローダウン。
- `all-policies-2024-2025-oos-combined.csv` — 2024+2025の合算、全方式・点数上限・券種。
- `red-to-black-full-family-and-ticket-budget-audit.csv` — 券種単位の赤字→黒字判定、年度別ROI、2年の買いレース数・利益。
- `summary.json` — ウォークフォワードとデータバージョンの厳密な契約と処理範囲。

この結果は「赤字の中に必ず持続的な黒字馬券がある」という仮説を支持してはいない。次の候補は馬番単位の順位差にとどまらず、**順序付き2着・3着の同時確率**を事前推定するチケット確率モデルへの改善。赤字からの転換を主張するには、年度をまたいだ持続的な利益が必要。
