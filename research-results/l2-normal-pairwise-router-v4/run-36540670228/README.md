# L2 Normal Pairwise Router V4

V1 remains the first-stage router. V4 only reranks V1 Top2 or Top3 candidates. The pairwise model sees pre-race Seven-King/race structure, template identities, and deterministic ticket counts. Odds, popularity, payouts and results are forbidden prediction inputs. V1_TOP1, TOP2_PAIRWISE and TOP3_PAIRWISE are compared on 2023-2024 only; 2025 is holdout-only. Every normal race remains in scope, no SKIP class exists, and 2026 remains sealed.
