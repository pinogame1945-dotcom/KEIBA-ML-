# L2 Trifecta Decomposed V1

Two-stage experiment: rank unordered podium trios, then rank the six finishing orders conditional on a trio. Final ticket score is normalized P(set) times normalized P(order|set). Market data is not a model feature and is used only for stage-1 hard-negative sampling, matching the COMPAT philosophy. 2023-2024 select one global Top-N; 2025 is frozen holdout; 2026 remains sealed.
