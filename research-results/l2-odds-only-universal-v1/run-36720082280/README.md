# L2 Odds-Only Universal V1

Seven-King/L1.7 information is completely removed. For each race and bet type, historical final odds are converted to normalized inverse-odds market probabilities. RAW_MARKET tests pure market self-consistency. POWER_CALIBRATED_MARKET applies a prior-year-only power calibration selected by winning-ticket negative log likelihood, never by ROI. Both variants use exactly probability * the same final odds > 1.0 as the buy rule. No edge floor, Top-K, ticket cap, odds band or race skip rule is used. 2026 remains sealed.
