# L2 Trifecta Ticket Ranker V1

The unit of learning is one trifecta ticket, not a hand-authored race rule. For every eligible race, all 120 ordered permutations of the Seven-King Top6 are scored by one model. There are no fixed seat rules, no market-gap buckets used as buy/skip rules, and no race skipping. 2023-2024 select one global Top-N ticket count; 2025 is frozen holdout; 2026 remains sealed. Final trifecta odds are represented only as normalized within-race market probability/rank, not raw odds. Payout/result fields are labels/evaluation only.
