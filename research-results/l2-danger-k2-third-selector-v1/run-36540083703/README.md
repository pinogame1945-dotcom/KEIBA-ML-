# L2 Danger K2 Third Selector V1

Keeps the BASE trifecta seat structure fixed and tests whether K2 novel horses can be pruned to Top1/Top2 by an exact-third classifier. The experiment never changes A1/A2 seats and never mixes in buy/skip, so any effect is attributable to K2 point reduction. Structural-only and structural+WIN-market models are compared against ALL K2 and frozen novel-order controls. 2026 remains sealed.
