# L2 Trifecta COMPAT Deep-Miss Audit V1

Diagnostic only. Reproduces the frozen 2025 COMPAT model and inspects exact winning trifectas ranked below 200. For each deep miss, it checks the consensus ranks of the actual 1st/2nd/3rd horses and the best model rank among all six permutations of that same podium trio. This separates horse-set blindness from finishing-order/seat assignment error. No new betting rule or filter is selected.
