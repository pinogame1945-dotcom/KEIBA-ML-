# L2 Oracle Funnel V1

This is a hindsight diagnostic funnel over already-selected Router actions. It does not retrain P(hit), rerun a Router, restore Kaggle/BACKFILL data, or touch 2026.

Stages are: candidate pool can form the official winning combination -> raw template contains a winning combination -> edge-filtered purchased action actually hits -> the race finishes with positive profit.

Candidate/template oracle rates are feasibility ceilings for diagnosis only; they are not production predictions and must not be interpreted as achievable ROI.
