# L2 TRIO CHAOS Predictor V1

Strict walk-forward test of whether V4 both-fail races can be identified before outcomes. 2024 is predicted from 2023 only; 2025 from 2023-2024. No winning-trio identity, result, payout, ROI, V4 ex-post probabilities/deltas, or 2026 data are features. Two feature sets run in parallel: L1.7+safe Outsider race structure, and the same plus full-race TRIO market-shape statistics.
