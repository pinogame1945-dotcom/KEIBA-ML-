# L2 Normal Role Structure Lab V1

PASS_SEVEN_ONLY races only. No race filtering and no K2 novel. This is the first coarse tournament for the roughly 90% normal battlefield: QUINELLA, EXACTA, TRIO and TRIFECTA using fixed Seven-King role templates. Every ticket is evaluated at 100 yen. The run compares ROI, total profit, race hit rate, average tickets per race, drawdown and jackpot concentration. No formation-width optimization is performed here. 2026 remains sealed.
