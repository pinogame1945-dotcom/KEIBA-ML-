# L2 TRIO Split Residual V4

Two clean market-residual engines are trained in parallel from shared preprocessing: MARKET+SEVEN_KING and MARKET+OUTSIDER. The Outsider engine uses the same frozen safe 13-candidate ballots as World Router and is canonically ordered by market rank, not Seven-King rank. Results include race-level strict walk-forward diagnostics for later World Router integration. No ROI, payout optimization, BUY/SKIP tuning, or 2026 data.
