# L2.1 K2 Novel Decomposition V1

This run decomposes the 5,577 frozen L15_FIXED_V1 K2 novel horses.

It does not select or tune a betting rule. Buckets were preregistered before this run. 2022-2024 remain development diagnostics and 2025 remains holdout confirmation.

Concentration tests report both dropping the largest winning ticket(s) entirely and the stricter counterfactual of keeping stake while zeroing those returns.

Outsider attribution is shown as exact source sets and fractional per-label attribution when both selected outsiders nominated the same novel horse.
