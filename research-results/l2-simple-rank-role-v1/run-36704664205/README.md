# L2 Simple Rank-Role V1

No model is trained here. L1.7 Seven-King full-field consensus is accepted as-is. Only ranks 1-3 are treated as focal horses, then deterministic AXIS/HIMO usage is evaluated with Top3 and Top6 partner pools. Every eligible race is evaluated; there is no gate, outsider, router, market filter, popularity feature, or race skipping. Payouts are used only after ticket construction for historical ROI measurement. 2026 remains sealed.
