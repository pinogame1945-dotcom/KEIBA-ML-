# L2 PRICER Contextual Volatility V2

One-shot comparison of deterministic PL, a prior-only static latent action, a learned contextual action-value policy, and a non-deployable test-outcome oracle. The contextual learner sees only pre-race frozen L1.7 diagnostics and predicts which volatility action minimizes expected trifecta log loss. Odds/ROI/ticket selection/staking are excluded. 2026 sealed.
