# AUTO FEATURE FACTORY V1

## 何をするものか

人間が一個ずつ特徴を手書きする代わりに、
安全な型だけを使って候補特徴を自動生成する。

v1は4系統だけ。

1. 過去の数値をまとめる
2. 同じ条件の過去成績をまとめる
3. 今回の出走馬の中で相対化する
4. 明示した2項目だけ差・比率を作る

## 1. 過去の数値

例:

- 平均
- 中央値
- 最小 / 最大
- ばらつき
- 直近値
- 前回との差
- 直近2 / 3 / 5回平均
- 最近を重くした平均
- 上向き / 下向きの傾向
- 欠損数
- 取得数

対象候補:

- 着順
- 着差
- 上がり3F
- 速度
- 距離
- 馬体重
- 斤量
- Elo
- 通過順位

## 2. 同条件

過去レースのうち今回と同じ条件だけを抜き出して、
回数・平均・成功率・傾向を作れる。

- 同競馬場
- 同芝/ダート
- 同距離
- 距離差100/200/300/400m以内
- 同じ右左
- 同じ内外回り
- 同じ馬場
- 同じクラス
- 同じ年齢条件
- 同じ斤量条件

BACKFILLにまだ無い項目は、値が来るまで自然に空になる。
推測で埋めない。

## 3. 今回メンバー内の比較

明示した数値だけについて、

- メンバー平均との差
- メンバー中央値との差
- z-score
- 上位から何番目か
- 百分位
- 1位との差
- 上位2頭平均との差
- 上位3頭平均との差

を作る。

「数値が高い方が良いか、低い方が良いか」を設定しない項目は計算しない。

## 4. 2項目の組合せ

全項目の総当たりは禁止。

人間または研究ルールが許可した組だけ、

- A - B
- A / B
- (A-B) / (|A|+|B|)

を作る。

## 安全柵

AUTO FEATURE FACTORYへ以下を材料として渡すことは禁止。

- target.*
- market.*
- final_win_odds
- final_popularity
- payout

つまり対象レースの答えや最終オッズから自動特徴を作らせない。

## まだやらないこと

v1を作っただけでは学習へ自動投入しない。

次段階で、

- どの元項目から自動特徴を作るか
- 何個まで作るか
- どれをwalk-forwardへ渡すか

を設定する。

特徴を選ぶ判断もholdoutを見る前に行う。


## 内回り・外回りの過去適性

AUTO段階では、BACKFILLの `course_layout` が存在する場合、
過去の同じ内外回りだけを抜き出した出走数・平均着順・3着内率・傾向を作れる。

同じ仕組みでクラス、斤量条件、馬場状態なども比較する。
BACKFILLに値が無い年代は推測で埋めない。


## 着差AUTO

BACKFILLの正式な `margin_type / margin_lengths` を過去レース材料として使う。

AUTO段階で作るもの:

- 数値着差の平均・中央値・直近値・ばらつき・傾向
- 0.5馬身以下、ハナ、アタマ、クビ、同着をまとめた小差率
- ハナ / アタマ / クビ / 同着などカテゴリ小差の割合
- 大差の割合
- 同競馬場・同距離・同内外回り・同クラス等での着差傾向

注意: netkeibaの着差欄をそのまま材料化するもので、「勝ち馬との差」とは決めつけない。
対象レース自身の着差はAUTOへ渡さず、過去日付の結果だけを使う。
