# L3 V1: 凍結L2.1馬券に対する「掛け金だけ」の一括比較（2026封印）

## 定義
- 根拠: 凍結コミット `9655c717333636b5cc931f672e12dbc377e396bc`。
- L2.1 STANDARD の **13,479物理馬券 / 6,877購入レース**をそのまま再使用。複数 line×gate との一致を重複購入しない。
- 未結合 L1.75 **215券も購入継続**。未知値を捏造せず追加資金の優先順位だけを下げる。
- ベースラインは全券100円。研究上の均等比較は**同一レース内の総投資額200円×購入券数**とする。すべての比較戦略で同じ購入レース・馬券、同じ投資額。
- その200円×Nを、全券最低100円（購入維持）を保証したうえで、各馬券最大300円の100円単位で配る。口数は常に正整数。

## 事前に固定した比較政策
`FLAT100` = 正本再現用100円均等。
`FLAT200` = 公平な200円均等。
`HASH_CONTROL` = ハッシュによるデータ無関係の比較対照。
`MIN_P3` = L1.75全構成馬中の最小3着以内確率。
`SUPPORT_MIN` = 最小Outsider支持。
`DELTA_MEAN` = 馬別3着以内確率補正の平均値。
`P3_SUPPORT` = p3と支持のレース内順位の平均。
`REVERSE_P3` = 信頼度の逆を増額する対照。
`LOW_FINAL_ODDS`, `HIGH_FINAL_ODDS`, `P3_HIGH_FINAL_ODDS` = **FINALオッズ利用であり事後診断専用。ライブ投入禁止**。

**禁止事項:** 馬券の追加・削除・0円化・軸変更・再順位・払い戻しを見た掛け金決定。
各レースで相対順位がタイの場合は馬券キー昇順で固定。券数Nに対しN個の追加100円口数を高スコア順に割り当て、1枚に追加できるのは2口まで。

## 出力
- `comparison.csv`: 戦略×年別および3年合計。ROI/絶対利益/的中数/上位3払戻除外ROI/日次決済P&L最大ドローダウン/最悪日/日次変動。
- `ticket_stakes.csv.gz`: 全馬券×政策の実際の購入金額・払戻シミュレーション。監査可能な一意キー。
- `summary.json`: 後知恵L2、FINALオッズ、2026封印の明示、日単位ペアブートストラップ参考区間。
- **2023〜2025全期間で選ばれたL2.1規則のままなので、どの指標も真正の未知年成績ではない。** 結果を見て優勝政策をそのまま実運用化しない。
- 信頼度`p3`は「馬が3着以内の確率」であって、馬連/三連複/三連単の正確な券的中確率ではない。Kelly最適化に転用しない。
- 過去の`FINAL`オッズは購入締切前に観測できた価格ではない。価格利用戦略は明示的に事後診断に閉じる。
- ドローダウンは**日末決済の累積損益**から計算。レース内一時的DDと混同しない。

## 実験の位置づけ
最初の研究は「1円単位でいくら賭ければ最高か」ではなく、固定原資下で資金配分が均等賭けに勝てるかを測る。以後のL3では (1) 同じ購入券群での破綻率・損失分布、(2) ユーザー予算ごとの最低購入額不足・レース合算制約、(3) 締切前オッズ実証と事前確率の検証、(4) ルールの固定後の将来ウォークフォワードを独立段階とする。

## 計算コスト
本研究はGitHub Actionsの無料標準CPU `ubuntu-latest`、Python標準ライブラリのみ。Artifact/Cacheアップロード・GPU・有料runnerなし。入力データは既存のリポジトリ内gzipファイルを再使用し、新しいKaggleダウンロードなし。結果は比較的小さいCSV/gzip/JSONのみ専用研究ブランチに保存。
