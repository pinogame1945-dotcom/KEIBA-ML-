# L3 V2 — トータル回収率を最適化する全馬券同時比較（2026-10-15）

**目的:** 個々の券種や過去の黒字帯を再発掘せず、L2.1が選んだ全13,479枚・6,877レースの買い目を100%維持したまま、全体として投入資金に対する払戻／利益／リスクが改善するかを一括判定する。

## 不変条件
- L2.1凍結契約は `9655c717333636b5cc931f672e12dbc377e396bc`。STANDARD 50 line×gate、9種の元買い方、軸・馬券集合不変。
- 全13,479物理馬券を購入。券の削除・追加・スキップ、0円賭けは禁止。L1.75欠損215点も維持、推測値の補完禁止。
- 2023〜2025年にL2.1を後知恵で採択しており、**結果はインサンプル**。2026年未知年は完全封印。
- L2.1が参照した過去の FINAL オッズは払戻後の確定値。締切前の実際の価格・注文成立を保証していない。L3は買い付け可能性を証明しない。
- 過去の着順・払い戻し・的中からその馬券のステークを算出しない（評価にのみ利用）。
- 各物理馬券最低100円。固定資金原則：`200円×購入点数`。比較は各レース単位もしくは開催日単位でこの資金を共有、年ごとに総額不変。
- 1枚上限300円、500円を**事前に固定**。前者＝弱い集中、後者＝強い集中。100円単位で配る。

## 一括候補群
- FLAT100: 凍結正本検算用。公平性比較の総投資額は半額なので参考のみ。
- FLAT200: 同額資金を使用する公正な基準。
- REVERSE_P3: 券構成馬の最小3着内推定確率が低い方へ追加。L3 V1で高収益だったため既知の後知恵仮説。
- OUTSIDER: 券構成馬のOutsider最低支持点が高い方へ追加。
- P3_OUTSIDER: 信頼度逆順位と支持点順位を同率で混ぜる。
- TRIFECTA_REVERSE / TRIFECTA_OUTSIDER: 三連単に優先配分。**V1の実績を見た後の探索候補であり、これによる勝利宣言は禁止**。
- FORWARD_P3: 信頼度が高いほど増額する反証対照。
- HASH: 入力スコアと無関係な疑似ランダム順位による対照。

各方式は（レース内配分・開催日内配分）両方を検証。主要5方式には上限300/500の2強度も交差させる。以上を**1回の標準CPUアクションにまとめる**。レース単位と日単位の全体ROI・全体損益を同じ総投資額で比較する。

### 解析出力
- `whole_portfolio_comparison.csv`: 総投資額、全体ROI、利益、上位3/10件の払戻を削除したROI、最大日末ドローダウン、最悪日、利益月割合、連敗日数、最大日次投資。
- `yearly_portfolio_comparison.csv`: 年ごとの成績。どれか1年だけ跳ねた効果を見抜く。
- `monthly_portfolio_profit.csv`: 月別全体損益。細切れの購入規則を生成するためには使わない。
- `paired_daily_bootstrap.csv`: 全期間日単位でペア差分の不確実性を表示。後知恵選択済みなので未来保証・独立テストではない。
- `full_portfolio_stakes.csv.gz`: 全政策×全券のステークを再現可能な台帳として保存。
- `summary.json`: 価格・未知年・研究限界・資金条件。

### 判断
単純に最大ROIの1個を選ぶのは誤り。**1) 全体利益改善、2) 年度一貫性、3) 高額払戻集中、4) ドローダウン**で共同評価。ヒントが見えてもさらに50種・1000種の閾値を追加してインサンプルを掘らない。

**検証の結論は研究用。** 将来時点で予測と発券可能なオッズを揃えた別時点の評価が行われるまで「儲かる完成モデル」とは扱わない。

## コスト・実行
無料 GitHub Actions `ubuntu-latest` CPU、Python標準ライブラリのみ。既存リポジトリ内で保存済み13,479券ファイルを流用。Kaggle再DLや、無意味な404推測リトライ、追加Artifact/Cache、GPU、有料runnerを使わない。凍結ブランチおよびmainは変更しない。
