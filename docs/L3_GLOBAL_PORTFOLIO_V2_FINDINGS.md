## 失敗耐性・残存する限界

1. 勝ち馬券上位3件を差し引いても低p3レース300のROIは114.21%、均等200円は102.62%。
2. **上位10件を差し引くと、全主要政策のROIは100%未満。** 低p3レース300でも93.36%。払戻上位依存の問題は依然大きい。
3. 過去のFINALオッズは、締切前に同じ価格で実際に購入できたことを証明しない。L2.1全体の実運用性には別途検証が必要。
4. `min_p3`は**券を構成する馬の最小3着内推定確率の代理**であり、L1.75の正式な信頼度ランクや馬券自体の的中確率ではない。
5. L2.1の規則は2023〜25で全年度黒字だったlineを同じ年度データから選んでいるため、上の3年黒字も独立な未知年証拠ではない。
6. L3 V1結果を見て組んだ一部政策、今回全26方式から見た上位の選択にも事後選択バイアスがある。2026封印を解禁しない。これ以上2023〜25の利益順位だけで探索を続けない。
