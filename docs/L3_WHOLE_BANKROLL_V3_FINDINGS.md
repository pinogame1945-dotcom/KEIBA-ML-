# L3 V3 全体資金管理・払戻悪化耐性の実測結果（2026-10-15）

実行: GitHub Actions **38718781530**、success（無料標準CPU）。出力場所: `research-results/l3-whole-bankroll-v3/run-38718781530/`。2023〜2025年のL2.1固定 **13,479券 / 6,877購入レース / 322開催日**を26配分方式で監査。馬券・軸・順位・券数・既存賭け金を変更しない。2026年を使用していない。

## 1. 全体回収率と必要原資

比較主軸は一律の総投資額 **2,695,800円**（1券平均200円）。レース単位の各戦略は元の買い目を維持して100〜300円を配る。

| 方式 | ROI | 3年利益 | 最低初期資金（日初全件前払） | 日末最大DD | 高額払戻TOP10除外ROI |
|---|---:|---:|---:|---:|---:|
| 均等200円 | 109.18% | +247,520円 | 23,600円 | 150,240円 | 88.51% |
| **低p3優遇・レース内300円** | **123.95%** | **+645,710円** | **7,800円** | 172,160円 | 93.36% |
| 低p3＋Outsider・レース内300円 | 121.89% | +590,040円 | 7,800円 | 136,670円 | 91.65% |
| Outsider支持・レース内300円 | 118.70% | +504,150円 | 7,800円 | **131,410円** | 88.48% |
| 低p3優遇・日単位300円 | **97.98%** | -54,510円 | **231,320円** | 343,040円 | 70.24% |

**解釈：**
- 同じ馬券集合に同額を投じても、レース内の増額先だけを変えることで過去のトータル回収率に差がついた。
- 低p3を開催日全体で優遇するのは逆効果。日内配分に極端に寄せる案はここで排除候補。
- **最低初期資金7,800円は過去の払戻と実際の開催日順序を既知として逆算した**必要額であり、おすすめの運用資金ではない。幸運な序盤の払戻が後半の損失を賄うから低くなる。初期資金10,000円で全日を購入できた事実は、将来の安全性を示さない。
- 日末最大DDは開始後の累積利益のピークから谷まで。最低初期資金の計算とは異なる。

## 4. 払戻金が減る場合の感度（仮想試験）

払戻を一律に5/10/15/20%引いた場合（本物の最終オッズ変動や発券条件のシミュレーションではない）：

| 方式 | 元ROI | -5% | -10% | -15% | -20% |

| 均等200円 | 109.18 | 103.72 | **98.26** | 92.80 | 87.35 |
| 低p3レース300 | **123.95** | 117.75 | 111.56 | 105.36 | **99.16** |

結果は「低p3レース300は一律15%の仮想減額でも回収率100%超、20%では赤字」という感度のみ。実際に市場からその価格を取得できることは別の問題。

## 5. 全体としての判断

1. **研究としての主候補:** `REVERSE_P3_RACE_MAX300` — 最大全体ROI、過去3年とも黒字、当時点の一般的なROI低下ストレスへの耐性が比較的高い。
2. **リスクとの両立候補:** `P3_OUTSIDER_RACE_MAX300` — ROI121.89%ながら、過去の日末最大DDは136,670円に縮小。
3. **主な失敗仮説:** 開催日全体にレース間の資金を移動させる低p3優遇は過去でも赤字、必要原資も約23.1万円まで跳ねる。
4. 高額的中TOP10を取り除くとどの主戦略でもROI100%を割る。大穴依存は解消できていない。
5. 最低必要初期資金7,800円は特定履歴の事後計算であり、推奨予算でも枯渇確率の保証でもない。

**全期間の本採用モデルはまだゼロ。** L2.1は過去3年全年度黒字による同期間選抜であり、FINALオッズは事後データ。ここまでの「改良」は正しい未知年の改善とは判定できない。以後はこの候補を原則固定して、これ以上2023〜2025年の黒字帯・券種を細切れに掘らず、締切前データと独立な将来の紙上購入ログで検証する。2026年封印を解禁せず自動購入もしない。
