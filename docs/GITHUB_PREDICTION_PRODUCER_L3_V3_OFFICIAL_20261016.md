# KEIBA ML — 2026-10-16 正本方針: GitHub側で予想を完結し、L3 V3を採用

## この文書の位置づけ

利用者の明示方針により **L3は研究版V3を公式の統合対象バージョンとして採用** する。これは **V3研究で比較した26のステーク政策から1本を選んだ** ことでも、**実際の当日レースで買い目と金額まで出せることを証明した** ことでもない。

この専用ブランチでは責務と採用バージョンだけを固定する。既存 `main`、凍結L2.1、MOBILE `main` は変更しない。対応する機械可読契約は `contracts/KEIBA_L3_V3_OFFICIAL_INTEGRATION_V1.json`。

## 責務の境界（以前の誤解を廃止）

1. **GitHub側**（KEIBA-MLと、必要な場合はKEIBA-BACKFILL等のGitHub管理ワークフロー）が、レースID（単数/複数）から出馬表・時点適格特徴量・必要なオッズを収集、保存・照合する。2026年の実レース入力の真偽は開催時点まで未検証でよい。途中で偽の値を埋めない。
2. **GitHub側** が既存L1のオッズ非補正AI順位（`AI_RAW`）、元の期待値AI順位（元 `ANCHOR_FULL` と元の市場価格の正本による定義を照合）、凍結L2.1 STANDARD、採用したL3 V3を順に実行し、レース別の完成結果を出力する。L1モデルが見つからなければ `BLOCKED`。独自の代理AIは禁止。
3. **GitHub側** が生成日時・根拠となる入力時点・モデル/ルールのバージョン・出力ステータスを持つバージョン付きJSONを公開する。現在、公開先（GitHub Pages / リポジトリのJSONファイル等）は実装・選択済みとは扱わない。
4. **スマホアプリは閲覧専用**。完成したJSONをGitHub側から受信して、`AI_RAW` 順位、期待値AI順位、L3 V3の買い目・購入金額を表示する。スマホでJRAからL2/L3用データを集め、スマホからGitHubに送ることを前提に**しない**。現存するMOBILEの旧JRA取得コードは今回削除しないが、新しいML実行系の依存先にはしない。
5. 複数レース出力も1レースと同じ契約を使う。レース単位の `READY` / `BLOCKED` と全体の状態を区別する。2026年の事後結果・確定オッズを封印済み研究に混入させない。

## L3 V3の正体と統合条件

- 正本の研究コードは `research/l3-whole-bankroll-v3-20261015`（`a12faef90c112713e3e0e6d460fe2482fafb6037`）の `research/run_l3_whole_bankroll_v3.py`、実行成功は Actions `38718781530`。
- V3は **V2で生成済みの26種の掛け金台帳を読み、全体資金残高・開催日の日初必要資金・資金不足・ドローダウン・払戻減額耐性を検証** するエンジン。単独の1レース推論器でも、26種から1つを自動選択するモデルでもない。
- 掛け金が決まった後、V3は金額を独断で変えない。全購入券を100円単位・最低100円で扱う。資金不足なら `INSUFFICIENT_BUDGET` を示し、勝手な部分購入・0円化・レーススキップ・当日払戻の先取りはしない。
- 当日全レースの資金制約を扱う場合、その開催日の対象券の必要原資を同日払戻前に確保する。単独レースでは利用可能な資金範囲を別途明示し、開催日全体の資金管理を実施したと偽らない。
- **未確定の1点：L3の1券ごとの資金配分方式。** V3自体の研究結果は `recommended_production_policy: NONE`。最大歴史ROIの `REVERSE_P3_RACE_MAX300`、より低い歴史DD候補の `P3_OUTSIDER_RACE_MAX300` などは選択候補であって、選択済みではない。ユーザーが特定方式を正式指定するまでは `BLOCKED_L3_V3_STAKE_POLICY_UNSELECTED` とし、100円均等をV3と偽装しない。
- 以前の1レース実装 `research/l3-one-race-money.py` は `BASELINE_FLAT_100_ALL_OR_NONE` の合成・紙上用で、**V3完成版ではない**。このファイルを無言で本番L3として流用・名称変更してはいけない。

## GitHub側からアプリへ渡すデータ

1レースJSONを最小単位とし、複数レースはそのリストとして束ねる。出力契約はまだ実装していないが、確定すべき項目は以下。

- `race_id`, `race_date`, `generated_at`, `source_as_of`, `model_versions`, `l2_contract`, `l3_contract`, `status`, `blocked_reasons`
- `rankings.ai_raw`: 元のオッズ非補正AI順位・horse_id・馬番・馬名・使用モデル根拠
- `rankings.expected_value`: 元の期待値AI順位・horse_id・馬番・確率/オッズ/EVに関する真正な計算値と参照時点（不明は `BLOCKED`）
- `l2_1.tickets`: 凍結正本で確定した物理馬券キー・券種・組合せ・価格・適用50条件の根拠
- `l3_v3`: 選択済み配分方式識別子、全馬券の購入金額、合計必要額、資金管理の結果、異常/資金不足理由
- ロギング・監査用: GitHub Actions run ID、ソースSHA/ハッシュ、当日データ時刻、重複/欠損の検査結果

アプリ側で計算・モデル再順位・買い目増減・賭け金決定はしない。詳細情報はGitHub側に残し、表示項目はアプリ側で選択すればよい。
