# L2.2 三連単万馬券の着順構造 — 2023–2025 全10,368R 実測

**集計完了（検証Run 38761110958）** https://github.com/pinogame1945-dotcom/KEIBA-ML-/actions/runs/38761110958

全3年間の公式確定三連単払戻のうち、100円あたり10,000円以上のレース（万馬券）を対象。対象レース総数10,368、2026は封印。予想や買い目選定には一切利用せず、「的中した3頭の人気順位」など結果が分かってからしか定まらない構造を記述する。

## 1. 発生件数・払戻階層

| 払戻（100円券） | レース数 | 全レース比 |
|--|--:|--:|
| <10,000円 | 2,908 | 28.05% |
| 10,000～29,999円 | 2,810 | 27.10% |
| 30,000～99,999円 | 2,497 | 24.08% |
| 100,000～999,999円 | 1,931 | 18.62% |
| >=1,000,000円 | 222 | 2.14% |

万馬券合計7,460/10,368レース = **71.95%**。各年2023=2,539/3,456、2024=2,436/3,456、2025=2,485/3,456。10万円以上は2,153R (20.77%)。

## 2. 1番人気の挙動

代表三連単的中馬券に1番人気が含まれる割合:
- 全レース 6,745/10,368 = 65.06%。
- 万馬券 3,983/7,460 = **53.39%**。
- 10万円以上 588/2,153 = **27.31%**。
- 非万馬券 2,762/2,908 = **94.98%**。

万馬券でも**半数以上が1番人気を含む**。10万円以上では1番人気が絡まない決着が主流。

## 3. 万馬券7,460Rの正解3頭に含まれる上位3番人気の頭数

| 上位3人気の頭数 | レース数 | 割合 |
|--|--:|--:|
| 0 | 695 | 9.32% |
| 1 | 3,703 | 49.64% |
| 2 | 2,999 | 40.20% |
| 3 | 63 | 0.84% |

万馬券の**89.84%**には市場上位3人気が1～2頭残る。逆に3頭すべてが上位3人気の万馬券は僅か0.84%。これは結果の分布であり、事前買い目への適用可能性は未検証。

## 4. 万馬券のどの着順に穴が来るか

万馬券内で、その着順の馬が**6番人気以下**である割合:
- 1着 18.50% (1,380/7,460)
- 2着 35.54% (6～9人気 1,907 + 10人気以下 744 = 2,651 / 7,460)
- 3着 45.44% (6～9人気 2,366 + 10人気以下 1,024 = 3,390 / 7,460)

**10番人気以下**:
- 1着 5.55% (414)
- 2着 9.97% (744)
- 3着 13.73% (1,024)

万馬券で1着は1～3人気が4,123/7,460 = 55.27%。人気薄は1着より3着に入る頻度が大きい。着順別の出現率であり確率補正後の価値（ROI）ではない。

## 5. 事前に判別可能な構造（分母つき）

| 出走頭数 | 全R | 万馬券R | 発生率 |
|--|--:|--:|--:|

| 15～16頭 | 4,241 | 3,434 | 80.97% |
| 17頭以上 | 881 | 758 | 86.04% |

出走頭数が増えるほど三連単の組み合わせ数も増える。距離別: 1400m未満77.53%、1400～1799m74.28%、1800～2199m68.33%、2200m以上65.25%。芝70.07%、ダート74.25%。表面情報不明108Rを別扱い。

出走頭数・距離・芝ダは事前観測可能だが、これだけでは予測可能な高配当の的中馬券が特定できるわけではない。確定払戻は後からしか見えず、パリミューチュエル方式の人気・点数と条件の交絡がある。

## 検証・誤差の扱い
- 公式レースパックをmanifest実在名から１回取得し、年度別に３並列集計。保存済みL2市場人気を流用。無料標準CPUのみ。
- 確定払戻が複数ある64Rは**最高払戻の1枚**を代表的中券として用いた。「万馬券レース」は１枚でも10,000円以上なら採用。100倍境界が混在する7Rは監査済み。
- 取消等によって保存済み人気１位が有効出走馬に存在しない32Rは、後から恣意的に人気順位を振り直さず、そのまま明示的に欠損扱いにした。
- 競馬AI学習・後知恵抽出・馬券購入ロジックの実装は**なし**。L2.1凍結資産不変。2026封印。
- 過去データの「実際に上位に来た人気順位」は事後情報。次の実装でそのまま購入条件にしてはならない。
